Regras e restrições da Moulinette (conforme o site)
Funções permitidas: nenhuma (o site exibe "None.").
Somente a sintaxe padrão do Python 3 é permitida. Não use pacotes de terceiros nem módulos proibidos.

Enunciado
Escreva uma função que encontre a interseção de várias listas ordenadas.
Retorne uma nova lista com os elementos presentes em TODAS as listas de entrada, em ordem crescente.

A função deve:
- Retornar somente elementos presentes em TODAS as listas.
- Ordenar o resultado em ordem crescente.
- Remover duplicatas do resultado.
- Tratar a entrada vazia e listas vazias.
- Retornar uma lista vazia se a entrada estiver vazia ou se qualquer lista estiver vazia.

Assinatura da função
def list_intersection_finder(lists: list[list[int]]) -> list[int]:

Exemplos

Exemplo 1
Entrada: list_intersection_finder([[1, 2, 3], [2, 3, 4], [2, 3, 5]])
Saída: [2, 3]

Exemplo 2
Entrada: list_intersection_finder([[1, 2, 3, 4], [2, 4, 6, 8], [4, 8, 12]])
Saída: [4]

Exemplo 3
Entrada: list_intersection_finder([[1, 1, 2, 3], [1, 2, 2, 3], [1, 2, 3, 3]])
Saída: [1, 2, 3]

Exemplo 4
Entrada: list_intersection_finder([[1, 2, 3], [4, 5, 6]])
Saída: []

Exemplo 5
Entrada: list_intersection_finder([])
Saída: []

Exemplo 6
Entrada: list_intersection_finder([[1, 2, 3], []])
Saída: []

Exemplo 7
Entrada: list_intersection_finder([[5]])
Saída: [5]
