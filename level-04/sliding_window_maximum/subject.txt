Exercício: py_sliding_window_maximum
Arquivo: py_sliding_window_maximum.py

Regras e restrições da Moulinette (conforme o site)
Funções permitidas: nenhuma (o site exibe "None.").
Somente a sintaxe padrão do Python 3 é permitida. Não use pacotes de terceiros nem módulos proibidos.

Enunciado
Escreva uma função que encontre o maior elemento em cada janela deslizante de tamanho k de uma lista. Retorne uma lista com o maior valor de cada posição da janela.

A função deve:
- Deslizar uma janela de tamanho k pela lista.
- Encontrar o maior elemento em cada posição da janela.
- Retornar uma lista com esses valores máximos.
- Tratar os casos especiais: lista vazia, k <= 0 e k maior que o tamanho da lista.
- Retornar uma lista vazia para entradas inválidas.

Assinatura da função
def sliding_window_maximum(nums: list[int], k: int) -> list[int]:

Exemplos

Exemplo 1
Entrada: sliding_window_maximum([1, 3, -1, -3, 5, 3, 6, 7], 3)
Saída: [3, 3, 5, 5, 6, 7]

Exemplo 2
Entrada: sliding_window_maximum([1, 2, 3, 4, 5], 2)
Saída: [2, 3, 4, 5]

Exemplo 3
Entrada: sliding_window_maximum([5, 4, 3, 2, 1], 1)
Saída: [5, 4, 3, 2, 1]

Exemplo 4
Entrada: sliding_window_maximum([1, 2, 3], 3)
Saída: [3]

Exemplo 5
Entrada: sliding_window_maximum([1, 2, 3], 4)
Saída: []

Exemplo 6
Entrada: sliding_window_maximum([], 2)
Saída: []

Exemplo 7
Entrada: sliding_window_maximum([1, 2, 3], 0)
Saída: []
