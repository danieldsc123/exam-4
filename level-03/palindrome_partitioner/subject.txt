Enunciado
Dada uma string s, encontre o número mínimo de cortes necessários para dividi-la de modo que cada substring resultante seja um palíndromo.

Um corte divide a string entre dois caracteres. Com c cortes, a string é dividida em c + 1 substrings. Encontre o menor número de cortes c para que todas as partes sejam palíndromos.

Retorne esse número mínimo de cortes como um inteiro.

Restrições:
- Uma string vazia ou com apenas um caractere exige 0 cortes.
- Se a string inteira já for um palíndromo, são necessários 0 cortes.
- No pior caso, quando todos os caracteres são distintos, o resultado é len(s) - 1 cortes.

Exemplos

Exemplo 1
Entrada: palindrome_partitioner("aab")
Saída: 1

Exemplo 2
Entrada: palindrome_partitioner("aba")
Saída: 0

Exemplo 3
Entrada: palindrome_partitioner("abc")
Saída: 2
